## Functionality

In general the functionality of my game should provide a loop of waves that occurs over the course required for atleast one player to get 20 eliminations to win. This will be through the use of generic player controls (WASD), shooting through the mouse cursor and the usage of modifiers to allow players to change the outcome of each round.

## Test Cases

Over the course of my coding journey regarding my digital outcome, I plan to use test cases. These test cases will outline the errors and successes that I made to encounter while repeatedly testing different features of my game. I plan to use "Google Spreadsheets" to make all my changes recorded in order of:

1. Test Case ID - Record of chronological order of each test case
2. Test Type - Boundary, Invalid or Expected Test Type
3. Test Scenario - Record of what kind of category the test case goes under
4. Test Case - What I am testing
5. Pre Conditions - The pre-requirements to preform the test
6. Test Step - Steps Taken
7. Input Data - Keys or Text Inputed
8. Expected Result - What I expect to occur
9. Actual Results - What eventually happens
10. Pass / Fail - If it meets the requirements or not

This ultimately makes it easier to keep track of all my stated changes so I can therefore use my changes from previous test cases to evolve my new code and to improve upon what I had done wrong before.
